# Critter Rescue
Original woodland rescue puzzle for Hambone Arcade. Select tools and draw directly on terrain; release the flock when ready. Four deterministic levels, local best stars, pause/fast-forward, touch and keyboard controls. No external dependencies.

The first prototype uses 2D Canvas with layered illustrative scenery and a fixed-step destructible tile simulation. Water is a static hazard rather than full fluid simulation; boulders fall and can be pushed. Cooperation is limited to guides redirecting the flock and the group sharing player-built paths. A later version can add agent-led construction and deeper physics.
